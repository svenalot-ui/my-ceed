# Мой Сид

Мобильный сайт-приложение (PWA) для учёта расходов на машину: заправки по фото чека, ТО и ремонты, поломки для мастера, напоминания (тест, страховка, ТО) и статистика.

- Без сервера и без регистрации — всё хранится на телефоне (IndexedDB).
- Чистый HTML/CSS/JS, без сборки. Открывать только через http(s), не через `file://`.
- Распознавание чека (Tesseract.js) подгружается с CDN при первом фото.
- `?demo` — демо-режим с выдуманными данными в отдельной базе.

Локальный запуск: `python3 -m http.server 5180` в этой папке → http://localhost:5180
